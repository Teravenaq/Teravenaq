## 🧠 Tentang Aku

> 🗿 *Berpendidikan tinggi* — baca buku, bikin tool, push ke GitHub dari browser.

- 🔭 Fokus: **web tooling** yang jalan 100% client-side
- 🌱 Prinsip: **tanpa server perantara, privasi dulu**
- ⚡ Fun fact: aku pernah push file ke GitHub **tanpa `git`** — cuma pakai browser
